# uxp_psd_che0-cu2-helper

## плагин для Фотошопа — быстро затянуть в 2% любую комбинацию из CMYK или убрать в 0% канал[ы] CMYK

Нужен мне при допечатной подготовке и цветокоррекции.

## Совместимость

Начиная с версии Фотошопа 22.0.0 (2020)

## Что плагин будет делать (начиная с версии 1.0.0)

* По нажатию кнопки `добавить cu` добавляет корректировочный слой `Curves`, настроенный (в согласии с установками 
  соответствующей секции интерфейса плагина) на то чтобы затянуть в 2% один или несколько каналов CMYK.
  По умолчанию активна привязка к слою. По умолчанию маска корректировочного слоя удаляется.
* По нажатию кнопки `добавить che` добавляет корриктеровочный слой `Channel mixer`, настроенный, в согласии с установками
  соответствующей секции интерфейса плагина, на то чтобы убрать в ноль один или несколько CMYK каналов.
  По умолчанию активна привязка к слою. По умолчанию маска корректировочного слоя удаляется.
* Состояние интерфейса сохраняется автоматически при каждом изменении.

## Как будет делать
 * Экшн фотошопа, скопированный, как js, будет использован в качестве шаблона.
 * Те или иные параметры будут динамически менятся в согласии с изменениями в интерфейсе плагина.
 * Верстка с элементами Adobe Spectrum из-коробки, без загрузки дополнительных веб-компонентов библиотеки Adobe Spectrum.
